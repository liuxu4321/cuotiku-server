# 管理端功能与验收

| 版本 | 日期 | 内容 |
|---|---|---|
| 1.23.0 | 2026-10-11 | 补齐小程序业务的网页管理入口，用户输出统一为 PDF 导出 |

## 入口与权限

部署同一服务端 jar，访问 `/admin/index.html`。原有用户管理、AI统计、客户端心跳及 Agent 配置保留；新增入口均调用既有 `/api/admin/mini/v1/**`，由服务端验证 ADMIN 权限。普通小程序用户不可调用管理接口。管理网页与 API 同源，无需另建前端服务或配置管理端微信域名。

## 功能清单

| 菜单 | 用途与操作 |
|---|---|
| 小程序账号与权益 | 按手机号、会员有效状态、启停筛选；新建账号、编辑会员名／会员号／到期日、启停／AI授权／角色；重置密码撤销会话；撤销会员只清除权益，不删除学生及错题 |
| 微信／学生（账号行操作） | 展示脱敏微信身份、绑定时间、账号资料及当前账号有效学生；不提供解绑、跨账号共享或代替用户修改题目 |
| 模板分类 | 新建分类、编辑名称、排序、启停；分类代码唯一性由服务端校验 |
| PDF模板 | 筛选分类／状态，创建模板身份，编辑名称／排序／启停；查看版本、编辑草稿、复制为新版本、发布 |
| 图片处理任务 | 按账号、学生、状态查询，详情展示固定输入、每个处理项与失败原因；填写原因，重试本任务的失败项 |
| PDF导出任务 | 查询任务、题数、模板版本、生成状态与快照；失败时填写原因按原快照重试；不新增纸张打印确认 |
| 对象存储资产 | 筛选归属、用途、状态，查看 COS 桶、区域、对象路径、大小；填写原因申请清理；后台检查引用、上传会话并异步删除 |
| 用户反馈 | 按账号／状态查询；标记新反馈、处理中、已解决、已关闭；保存内部备注，用户接口不显示内部备注 |
| AI调用明细 | 按账号、学生、供应商、类型、成功状态、traceId及日期查询；查看Action、RequestId、耗时、字节和Token明细 |
| 消息队列 | 查询投递事件、状态、尝试次数；填写原因重试失败消息 |
| 数据诊断 | 按账号／学生检查缺少学生归属、跨学生引用、孤立资产和旧索引警告；只诊断，不自动改用户资料 |

## 模板操作流程

1. 新建或选择模板分类（A4、B5或其他），增加模板名称与唯一代码。
2. 进入版本列表，新建草稿；填写纸张宽高（毫米）、方向与每页题数。
3. 点击生成均分题框，也可编辑声明式布局JSON；预览SVG示意图。默认A4为210×297毫米，其他规格手动填写准确尺寸。
4. 保存时上传受控SVG并保存完整草稿；纸张参数、题数与布局必须一致。代码内容只作受控版本字段存储，页面不执行任何脚本。
5. 回到版本列表，发布草稿。发布版本不可修改；后续修改通过复制为新版本完成。旧PDF继续引用旧快照。
6. 在小程序中选择模板、导出PDF，验证真实题图清晰度和分页；SVG预览只用于确认版式。

## 状态与恢复

- PDF的READY和历史PRINT_CONFIRMED在管理列表均显示“PDF已生成”，后端接口命名继续保留print-tasks以兼容现有数据。
- 列表使用服务端游标，支持上一页／下一页与筛选重置；切换菜单后不接受旧列表响应。
- 重试和清理必须填写原因；未知网络结果保留原请求键供原操作重试，明确4xx错误解除该请求锁定。
- 管理敏感操作沿用现有MiniAdminAudit拦截器和任务事件记录；不将密码、令牌或验证码写入诊断输出。
- 后台资产清理只申请异步删除，有业务引用时拒绝；不提供批量一键清理。

## 验证命令

```bash
node --test checks/admin-console.test.cjs
mvn test
mvn -q -DskipTests package
```

JS交互测试复用同工作区yycuotiku的jsdom开发依赖；独立运行时需预先安装jsdom。测试覆盖筛选／翻页、反馈内容转义、模板SVG与版本保存顺序、只重试失败项、未知结果幂等、迟到响应和账号字段。服务端测试使用Testcontainers MySQL，真实云调用仍按环境条件跳过。
