# 拾星错题本：用户业务需求与 User Story

版本：业务需求基线 v1.0。日期：2026-10-10。

依据：已确认 UI、`DATABASE-MODEL.md` 与后台 `ORM-MAPPING.md`。本文定义目标行为及验收要求，不代表故事已开发完成；ORM 完成只说明实体已映射，新增接口、会员绑定、队列、云任务和前后端联调仍需按故事实现。

## 1. 用户角色与权益边界

| 业务角色 | 定义 | 模型对应 | 业务边界 |
|---|---|---|---|
| 系统管理员 | 管理账号、模板、AI配置和系统运行的后台人员 | sys_user.role=ADMIN | 仅后台管理能力，不能让普通账号伪造身份获得权限 |
| 普通用户 | 无有效会员权益的使用者；包括未绑定微信身份和已绑定的非会员／到期账号 | 未绑定 user_identity；或 role=USER、会员非有效 | 未绑定可看公开内容并绑定；已绑定可管理自己的基础学习资料 |
| 会员用户 | 已绑定且具有有效会员权益的用户 | role=USER；会员到期日／权益有效性 | 继承普通用户基础能力；智能功能另受 ai_enabled、配置启用及配额控制 |

学生是账号下的业务档案，不是第四种登录角色。会员也不是新增 Role.MEMBER；同账号从普通状态变为会员，不复制或移动学生数据。

**权限划分建议，需与商业规则确认：**本文以“已绑定用户可使用学生、分类、手动采集整理、练习、基础模板打印和随机组卷；会员具备申请智能服务的业务资格”为需求基线。现有代码有独立 ai_enabled 开关，不能未经确认将普通用户的已有 AI 授权收回，也不能仅凭会员号开通 AI。会员有效是否为新 AI 请求的强制条件、免费配额与模板收费范围见第 8 节待确认项。没有确认前，不在代码硬加收费门槛。

这里的“绑定账号”要求凭据有效、账号启用，不等同于“会员权益未到期”。模型文档中“有效会员账号”按此解释，避免会员到期导致基础数据无法访问。

## 2. 能力矩阵

“基础”指本文建议范围；“按授权”指实际 ai_enabled／供应商配置／配额允许；最终收费策略仍待确认。

| 能力 | 未绑定普通用户 | 已绑定普通用户 | 会员用户 | 系统管理员 |
|---|---|---|---|---|
| 查看帮助与关于 | 可以 | 可以 | 可以 | 可以 |
| 微信身份识别／会员账号绑定 | 可以 | 已绑定信息查看 | 已绑定信息查看 | 后台排障 |
| 新增／切换学生与分类 | 引导绑定 | 基础 | 继承基础 | 诊断归属 |
| 拍照／导入／手动框题／保存 | 引导绑定 | 基础 | 继承基础 | 不代替用户采集 |
| 错题查询／修改／删除／做题 | 引导绑定 | 基础 | 继承基础 | 经明确权限诊断 |
| 模板打印／任务／随机组卷 | 引导绑定 | 基础，收费范围待定 | 继承基础 | 管理模板／排障任务 |
| 腾讯云增强／去手写／自动框题 | 不发真实请求 | 按既有授权；商业门槛待定 | 按授权，不自动开通 | 配置、审计、任务排障 |
| AI讲解／举一反三 | 不发真实请求 | 同上 | 同上 | 配置与审计 |
| 在线意见反馈 | 可看页面，提交引导绑定 | 可以 | 可以 | 处理反馈 |
| 管理账号／会员权益／模板／配置 | 禁止 | 禁止 | 禁止 | 可以 |

## 3. 普通用户故事

P0 为完整主流程所需；P1 为后台运维或增强能力。每条故事列明页面、实体与可验证条件，不强行用优先级表示会员价格档次。

### USR-01 · 微信进入与身份识别

作为**普通用户**，我希望通过微信进入小程序并识别我的身份，以便下次进入时继续使用自己的账号资料。

**优先级：**P0。 **入口：**小程序启动、我的。

**关联实体：**user_identity、sys_user、user_profile。

**验收条件：**

1. 后端使用微信登录 code 获取当前 AppID 的 openid；同身份重复进入不创建重复记录。
2. unionid 未提供时仍可建立身份；不能依赖自动获取微信昵称和头像。
3. 未绑定时我的页面 Logo 右侧显示“绑定会员号”，不伪造会员名／号。
4. 未绑定身份仅访问公开内容；正式学生与错题业务前引导绑定账号。

### USR-02 · 手机号密码与图形验证码绑定账号

作为**普通用户**，我希望使用手机号、密码和图形验证码绑定已有账号，以便把微信身份与我的学习数据关联。

**优先级：**P0。 **入口：**我的 → 绑定会员号。

**关联实体：**captcha_challenge、user_identity、sys_user。

**验收条件：**

1. 表单包含手机号、密码、图形验证码输入框与图片，点击图片刷新，不发送短信验证码。
2. 后端原子校验并消费验证码，再验证账号凭据和启用状态；任何失败都不建立绑定。
3. 验证码过期、输入错误、密码错误、账号停用分别给出可操作提示；密码不回显、不持久保存。
4. 绑定成功显示服务端返回的会员名、会员号；重复提交不产生多条身份。
5. 已绑定身份不允许客户端提交另一会员号静默覆盖；账号绑定的数量策略见待确认项。

### USR-03 · 查看账号身份与权益状态

作为**普通用户**，我希望在我的页面看到账号会员名、会员号和可用能力，以便知道自己使用的是哪个账号以及功能是否可用。

**优先级：**P0。 **入口：**我的。

**关联实体：**sys_user、user_identity、user_profile。

**验收条件：**

1. 会员号非空不代表权益有效；到期、停用和 AI 未授权的提示区分。
2. 头像旁展示账号信息，不再用学生昵称代替会员名。
3. 权益状态由服务端返回；普通账号无有效权益仍可查看已归属自己的基础数据。
4. 会员状态不改变账号 ID，也不转移学生或错题归属。

### USR-04 · 新增与编辑学生

作为**普通用户**，我希望给账号配置多个学生并填写昵称、年级、学期，以便分别管理每个孩子的学习资料。

**优先级：**P0。 **入口：**我的 → 配置学生 → 增加学生／编辑。

**关联实体：**student_profile。

**验收条件：**

1. 列表以卡片展示昵称、年级、学期与当前学生标识，底部固定增加学生按钮。
2. 昵称必填；年级为 1～12，学期为上／下学期；昵称可重复，身份用 ID。
3. 编辑后首页胶囊立即展示当前学生昵称；年级从学生资料取得。
4. 年级更新只影响新错题录入快照，不修改历史年级／学期。
5. 一个学生只能归属一个账号，不提供共同管理、邀请或跨账号共享。

### USR-05 · 切换当前学生

作为**普通用户**，我希望在学生卡片列表切换当前学生，以便只看到这个孩子的错题和采集打印内容。

**优先级：**P0。 **入口：**首页右上角胶囊 → 我的 → 配置学生。

**关联实体：**user_profile、student_profile及学生业务实体。

**验收条件：**

1. 首页胶囊显示当前学生昵称与向右箭头；点击跳我的页面。
2. 只有一个学生时自动选中；没有学生时引导增加。
3. 切换后重查错题、最近拍摄、分类和打印任务，记住最近使用学生。
4. 不能把旧学生的已选题目带入新学生打印草稿；拍摄处理中的批次仍归属打开时的学生。
5. 非法或他人 student_id 返回拒绝，不使用最近学生隐式替代请求作用域。

### USR-06 · 配置科目

作为**普通用户**，我希望增加科目并查看科目列表，以便按实际学习内容整理错题。

**优先级：**P0。 **入口：**我的 → 配置科目。

**关联实体：**user_subject、student_profile。

**验收条件：**

1. 入口位于配置学生下方；科目列表底部提供增加科目按钮。
2. 名称去首尾空白并规范化去重，同一学生不可重复；不同学生可同名。
3. 科目配置成功后错题保存和筛选的科目选项同步更新。
4. 点击科目进入该科目的主题设置，而不是直接编辑错题。

### USR-07 · 配置科目主题

作为**普通用户**，我希望在某个科目下增加主题，以便更精细地归类和筛选错题。

**优先级：**P0。 **入口：**配置科目 → 科目 → 主题设置。

**关联实体：**subject_topic、user_subject。

**验收条件：**

1. 页面明确当前科目，列表只显示该科目主题，底部提供增加主题按钮。
2. 同学生同科目规范化名称不可重复；不同科目可以有同名主题。
3. 新增主题立即可用于保存错题；选择科目后只提供其所属主题。
4. 主题必须与科目和学生归属一致，不能跨科目引用。

### USR-08 · 配置错误类型

作为**普通用户**，我希望添加适合孩子的错误类型，以便根据真正的错误原因进行复习。

**优先级：**P0。 **入口：**我的 → 配置错误类型。

**关联实体：**error_type。

**验收条件：**

1. 入口位于配置科目下方，错误类型列表底部提供增加按钮。
2. 支持计算错误、审题不仔细等自定义类型，不限制为四个中文选项。
3. 同学生规范化名称不可重复，ID／code 稳定，不通过中文名称临时推断抽题分类。
4. 新增类型用于保存、搜索和新随机组卷；旧四大类只作兼容映射。

### USR-09 · 单张与多页拍摄

作为**普通用户**，我希望用全屏取景区拍照并选择单张或多页模式，以便快速采集一道题或多页试卷。

**优先级：**P0。 **入口：**首页 → 录入错题 → 拍照上传。

**关联实体：**capture_batch、capture_photo、media_asset。

**验收条件：**

1. 页面使用与微信胶囊对齐的正常返回按钮，中间以取景区为主体。
2. 底部依次为文件夹图标的最近拍摄、快门、相册导入。
3. 取景区上方多页模式可点击选中／取消；单张拍完直接进入照片处理页。
4. 多页拍摄后仍停留取景，右下显示缩略图、张数与完成按钮，点击完成进入处理页。
5. 相机权限拒绝时可再次授权或使用相册，避免空白死页。
6. 取消多页模式时如有已拍照片须明确保留／处理，不能无提示丢失。

### USR-10 · 相册导入与最近拍摄

作为**普通用户**，我希望从相册或最近拍摄中选择图片，以便复用已拍资料而不重复拍摄。

**优先级：**P0。 **入口：**首页相册导入、拍摄页最近拍摄。

**关联实体：**capture_batch、capture_photo、asset_upload_session、media_asset。

**验收条件：**

1. 相册支持一张或多张，确认后进入统一照片处理页；取消选择不生成空批次。
2. 最近拍摄只显示当前学生、当前账号有权访问的有效记录。
3. 图片显示上传进度；上传失败可重试，服务端校验成功前不进入需要该资产的处理。
4. 重试使用稳定请求键，不能重复创建同一批次项；文件大小／格式限制由服务端配置返回。

### USR-11 · 浏览与删除待处理照片

作为**普通用户**，我希望左右滑动浏览照片并删除不要的图片，以便只保留需要整理的内容。

**优先级：**P0。 **入口：**照片处理页。

**关联实体：**capture_photo、image_revision、media_asset。

**验收条件：**

1. 导航标题显示第几张／共几张，随滑动和删除变化。
2. 图片右上角显示删除图标；删除后当前索引保持有效。
3. 按下查看原图显示原始资产，抬起恢复处理图，不修改当前版本。
4. 删除最后一张后显示空状态并禁止保存／打印，允许返回采集。
5. 删除工作区照片不删除已经保存的错题或历史打印快照。

### USR-12 · 手动框题与选择待保存题目

作为**普通用户**，我希望手动框选题目并确认保存范围，以便在没有自动识别时也能整理错题。

**优先级：**P0。 **入口：**照片处理 → 框题。

**关联实体：**question_region、image_revision、media_asset。

**验收条件：**

1. 题框绑定确切图片版本，允许增删和调整，区域不超出图片范围且有有效面积。
2. 框题后按选中题框分别裁切；未框题时明确按整图保存，不声称已识别为多道题。
3. 框题工具不要求覆盖原图，保留来源和顺序。
4. 手动范围及选题在保存／打印前由服务端复核；自动框题能力见会员／AI故事。

### USR-13 · 分类保存错题

作为**普通用户**，我希望选择科目、主题和错误类型后保存所选题目，以便把采集内容变为可查询的错题记录。

**优先级：**P0。 **入口：**照片处理 → 保存 → 保存错题。

**关联实体：**book_entry、question_region、book_add_idempotency、分类实体。

**验收条件：**

1. 保存页没有顶部额外提示，提供科目、主题、错误类型和保存按钮。
2. 分类必填且属于批次学生；年级／学期取该学生保存时的有效资料并存历史快照。
3. 同一批图片可共用分类，但每个选中题框／整图生成独立错题。
4. 重复提交同请求同内容不重复保存；同键不同学生／内容返回冲突。
5. 全部成功后提示保存成功；部分失败清晰标出失败项，可仅重试失败部分。

### USR-14 · 搜索与选择错题

作为**普通用户**，我希望用科目、主题、错误原因和日期搜索并选题，以便快速找到要复习或打印的错题。

**优先级：**P0。 **入口：**错题集。

**关联实体：**book_entry、分类实体。

**验收条件：**

1. 页面名称使用导航标题，不再重复显示第一行错题集文字。
2. 顶部按钮按全选、打印所选、放大镜搜索排列；全选为按钮，不用 checkbox 样式。
3. 搜索抽屉含科目、主题、错误原因和日期，支持重置；开始日不能晚于结束日。
4. 列表卡片左上 checkbox 紧接分类文字；显示缩略图，时间只到日期。
5. 查询和选择只在当前学生范围；无结果显示空状态，筛选改变后清理失效选择。

### USR-15 · 统一详情、修改与删除

作为**普通用户**，我希望从首页或错题集进入同一个详情页并维护题目，以便避免不同入口展示不一致。

**优先级：**P0。 **入口：**首页消灭错题、错题集 → 错题详情。

**关联实体：**book_entry、media_asset、分类实体。

**验收条件：**

1. 详情第一行显示科目、主题、错误原因，无下方附加小字。
2. 紧接一排做、讲、练及打印、修改、删除图标；下方正常显示图片与错题信息。
3. 首页列表有做题和删除按钮；点击列表项进入统一详情页。
4. 修改校验分类及乐观锁；版本冲突提示刷新，不覆盖他人最近修改。
5. 删除需确认且软删除，取消不变；不影响历史打印快照，详情刷新后给出已删除状态。

### USR-16 · 做题并记录练习

作为**普通用户**，我希望提交作答及结果并回看练习记录，以便知道哪些题练过和是否掌握。

**优先级：**P0。 **入口：**错题卡片／详情 → 做。

**关联实体：**book_practice_record、book_entry。

**验收条件：**

1. 做题提供题图和提交结果入口；是否自动判题由后续能力决定，不将查看答案视为提交。
2. 提交保存作答、正误、时间及可用用时，幂等重试只计一次。
3. 练习次数、正确次数、最近练习时间与历史记录一致；打开题目不计数。
4. 掌握规则可独立配置；不能无明确规则就把一次正确当作永久掌握。

### USR-17 · 选题并使用通用模板打印

作为**普通用户**，我希望勾选错题、选择模板后提交打印，以便获得适合纸张排版的复习资料。

**优先级：**P0。 **入口：**错题集打印所选、详情打印、照片处理直接打印。

**关联实体：**print_template_category/version、print_task/item、media_asset。

**验收条件：**

1. 所有入口进入同一模板选择打印页，顶部提示先选模板再点击打印。
2. A4、B5各一行示意图，可左右滑动；分类小字在下方，后续分类动态加载。
3. 缩略图使用 SVG；下方题目列表一行一个，右侧垃圾桶只移除草稿项。
4. 没有模板或没有题目时不允许打印，选择模板本身不创建任务。
5. 点击打印校验来源并生成不可变题图、分类、模板快照；同请求重试仅一任务。
6. 保存错题不是直接打印的前提，直接采集打印可不填写分类。

### USR-18 · 随机组卷

**优先级：**P1。 **入口：**后台打印任务管理。

**关联实体：**print_task/item/event、print_template_version、media_asset。

**验收条件：**

1. 可查询 ID、学生归属、模板版本、题数、份数、页数和输出资产状态。
2. 重试渲染使用原快照；改变模板／题目需新建任务，不偷偷改历史。
3. READY 只表示文件生成，真实确认打印另存回执／事件。
4. 失败、重试、取消、下载和确认打印有事件记录，用户仍只访问自己的任务。

### ADM-12 · 管理 COS 资产生命周期

作为**系统管理员**，我希望检查上传、对象可用状态和清理候选，以便控制存储占用并避免误删历史文件。

**优先级：**P1。 **入口：**后台资产诊断／清理任务。

**关联实体：**media_asset、asset_upload_session、错题／打印／图片引用。

**验收条件：**

1. 私有题图只通过鉴权代理／短期签名访问，不把签名 URL 当长期字段。
2. 区分旧 LEGACY_PACKAGE ZIP 和独立图片／PDF／SVG，上传 Content-Type 与内容一致。
3. 删除前检查所有引用和运行任务；任务快照引用的题图不能按批次到期删除。
4. 删除失败保持待删并重试，COS 确认成功才标记 DELETED。
5. 上传声明不等于可用资产，完成需验证大小、类型、摘要；密钥不进入业务数据。

### ADM-13 · 处理用户反馈

作为**系统管理员**，我希望查看和标记反馈处理状态，以便了解问题并推进解决。

**优先级：**P1。 **入口：**后台反馈管理。

**关联实体：**user_feedback。

**验收条件：**

1. 展示反馈内容、提交账号、时间、客户端版本及 NEW／REVIEWING／RESOLVED／CLOSED。
2. 可保存内部备注，用户不能修改管理员备注或处理状态。
3. 同请求重试只有一条反馈；不把反馈默认公开给其他用户。
4. 若需要给用户发回复，另确认消息渠道和授权，当前不自动发送站外消息。

### ADM-14 · 监控客户端与任务投递

作为**系统管理员**，我希望观察客户端状态、任务队列积压和失败重试，以便判断系统运行是否正常。

**优先级：**P1。 **入口：**现有心跳管理／任务运维。

**关联实体：**client_keepalive、outbox_event、processing_job、print_task。

**验收条件：**

1. 心跳保留账号／版本／最近在线时间，不混入学生数据归属或机密信息。
2. Outbox 与业务任务同事务创建，消费者可幂等处理重复投递。
3. 投递失败可重试并监控积压；不能任务已入库但工作永久丢失。
4. Outbox 可由数据库任务轮询替代，必须有同等恢复保障。

### ADM-15 · 检查历史数据升级兼容

作为**系统管理员**，我希望在启用多学生能力前完成默认学生回填和索引检查，以便避免新模型上线破坏现有用户。

**优先级：**P0。 **入口：**上线前数据升级核查。

**关联实体：**所有历史业务实体、student_taxonomy_pref、ORM辅助生成列。

**验收条件：**

1. 现有账号历史记录映射默认学生，不凭混杂年级猜测多个孩子。
2. 回填分类、错题、练习和 AI 归属，检查跨学生引用／孤立行。
3. 旧偏好保留兼容，学生偏好独立；清理旧唯一索引前确认新作用域约束有效。
4. 旧 COS ZIP 读取兼容保留；不把 ddl-auto 自动加列视为数据迁移完成。
5. 未完成隔离前不能以 UI 多学生按钮已存在为由宣称后台可安全切换。

## 6. 共通业务约束

### SYS-01 · 跨账号与学生隔离

**要求：**每个业务请求显式账号认证与 student_id，照片、区域、版本、分类、题目、任务和资产关联逐级验证；ID 不是访问凭证。缓存键／草稿按学生分开。

**关联：**所有学生业务实体。

### SYS-02 · 并发与幂等

**要求：**上传、批次、保存、处理、练习和打印采用稳定请求键；同键同内容复用，同键不同内容／学生冲突。版本锁拒绝旧客户端覆盖。

**关联：**幂等字段、book_add_idempotency、版本列。

### SYS-03 · 时间、分页与数量

**要求：**数据库 UTC，UI 上海时区；日期筛选半开区间，日期显示不丢完整时间；分页以 created_at+id 游标；题数／份数／页数分开。

**关联：**审计字段、print_task。

### SYS-04 · 资产与事务一致性

**要求：**COS 与数据库不在同一事务中；上传会话、AVAILABLE 状态、补偿和清理保证引用有效。原图、已发布版本和打印快照不可被业务修改覆盖。

**关联：**media_asset、版本／快照、outbox_event。

### SYS-05 · 可恢复的空状态与异常

**要求：**没有学生、没有分类、没有照片、没有错题、没有模板、没有打印任务分别给明确下一步；相机拒绝、离线、上传失败、AI失败和渲染失败可恢复，不展示假成功。

**关联：**页面状态与任务状态。

### SYS-06 · 授权与隐私

**要求：**密码、微信密钥、云密钥、JWT 和验证码答案不进普通业务日志／持久草稿；验证码一次性。用户操作归属服务端验证；管理员操作审计不足的功能不得直接上线。

**关联：**sys_user、身份、验证码、调用日志、后台审计。

### SYS-07 · 兼容与真实能力说明

**要求：**Demo、本地保存、ORM已映射、API已接入、云任务已运行分开标示。保留旧四类映射与 ZIP 读取；会员／AI 不可用时不影响既有数据归属。

**关联：**全链路。

## 7. 用户主流程与落地顺序

### 7.1 三条主要学习流程

1. 微信进入 → 未绑定时手机号＋密码＋图形验证码绑定 → 配置／选择学生 → 配置分类。
2. 拍照／导入 → 照片处理（手动或已授权 AI）→ 保存 → 分类 → 错题集；或直接进入模板页 → 选模板 → 打印任务。
3. 错题集选题／详情打印／随机组卷 → 同一模板打印页 → 调整草稿／选模板 → 点击打印 → 任务生成 PDF → 获取输出／明确确认打印。

### 7.2 管理端流程

管理员登录 → 管理账号及权益 → 配置模板与 Agent → 查询调用／任务／资产／反馈 → 根据权限恢复失败工作。需要新管理入口的故事并不表示现有静态后台已经有对应菜单。

### 7.3 推荐实施分组

| 分组 | 故事范围 | 交付验收 |
|---|---|---|
| 身份与学生隔离 | USR-01～08，MEM-01，ADM-01～05／15，SYS-01／06 | 登录绑定、学生及分类API与旧数据隔离正确 |
| 基础采集和错题 | USR-09～16，SYS-02～05 | 上传、手动框题、保存、查询、修改、练习端到端 |
| 通用模板与打印 | USR-17～19，ADM-06／07／11／12／14 | 三种入口共用模板页，快照、PDF、任务可恢复 |
| 智能处理和学习 | MEM-02～09，ADM-08～10 | 真实腾讯云与 Agent 集成、授权、调用审计与版本正确 |
| 服务与权益连续性 | USR-20，MEM-10，ADM-13，SYS-07 | 帮助、反馈、关于、到期行为及真实能力文案 |

会员故事继承普通故事，不建立第二套采集／错题／打印业务。若分阶段上线，未交付功能明确占位，不用仅生成成功 toast 代替后台业务验收。

## 8. 尚需确认的商业与运营参数

这些参数不改变已确认实体结构；未确认时采用保守配置，不虚构套餐或实施收费。

| 事项 | 已明确 | 待确认 |
|---|---|---|
| 普通与会员功能边界 | 账号与权益独立；AI另有授权 | 普通用户免费业务范围；有效会员是否为新AI调用必要条件 |
| 使用额度 | 需要服务端计量与超限提示 | AI次数／字节／token额度、周期、失败计费、重置时区 |
| 学生／科目／题目规模 | 一账号多学生，学生隔离 | 每账号学生数、图片大小／批次张数、存储／题量上限 |
| 模板权益 | 所有来源使用同一模板打印页 | 是否存在会员专属模板，模板付费不属于当前已确认功能 |
| 到期历史访问 | 不删除档案或快照 | 历史PDF下载、已有AI结果查看的权益边界 |
| 身份绑定策略 | 一微信身份只关联一个账号 | 同一会员账号可绑定几个微信身份，绑定变更的人工处理流程 |
| 随机组卷 | 按错误类型题数、少练优先 | 是否后续提供额外抽题策略；首期不加入复杂规则 |
| 练习掌握规则 | 提交才计数 | 连续正确数、人工标记、掌握后是否参与组卷 |
| 保留与清理 | 引用中的资产不能误删 | 未保存批次、日志、任务及已生成PDF的具体保留天数 |
| 管理审计 | 需要追溯敏感变更 | 通用管理员审计实体尚未建模；管理改权、重试等上线前补设计 |
| 实际纸张打印 | PDF生成不代表实际输出 | 是否接外部打印服务；未接时以下载／分享／用户确认闭环 |

## 9. 明确不在范围内

- 不支持父母共同管理、跨账号共享孩子、邀请／监护关系，今后也不扩展此类功能。
- 不恢复玩具箱、学习笔记、我的成长、底部设置、我的打印记录和默认模板菜单。
- 不把本次故事扩展为支付、商城、会员充值、社交或站外消息功能。
- 不新增没有业务意义的错题集容器表，不把选模板动作直接写成打印任务。
- 不把系统管理员当作默认可无审计读取所有孩子原图／代替用户答题的角色。

## 10. 追溯与完成定义

本文件是业务需求基线，完整实体说明见 `DATABASE-MODEL.md`，ORM现状见后台 `docs/ORM-MAPPING.md`。每个实现任务引用故事 ID，验收同时覆盖正常、空数据、无权限、失败重试和重复提交。

故事完成需要真实后端授权与持久化、对应页面联动及必要测试；仅完成实体、Repository、占位页或本地存储不算完整业务交付。腾讯云／COS真实调用测试应使用授权测试环境，不把带密钥的调用混入常规测试。
